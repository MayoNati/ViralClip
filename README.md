# ViralClip

ViralClip is a desktop video editor application designed to help content creators easily edit and upload videos to TikTok.

## Features

- Video editing tools optimized for social media content
- Direct integration with TikTok API for seamless uploads
- Local data storage for privacy and security
- User-friendly interface for quick video creation

## TikTok API Integration

ViralClip uses the TikTok API with the following scopes:
- `user.info.basic`: Access to basic user profile information
- `video.upload`: Ability to upload videos to your TikTok account

## Privacy

ViralClip stores all your data locally on your device. We do not sell or share your personal information with third parties. For more details, see our [Privacy Policy](PRIVACY_POLICY.md).
